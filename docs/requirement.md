# 林林总总 需求说明书
版本：V1.0
日期：2026/7/17

# 1.项目概述
## 1.1 项目名称

	林林总总

## 1.2 项目目标

	开发一个个人记账软件，用于记录日常收入和支出。

	本项目主要用于学习Linux环境下的软件开发流程，
	包括：
	
	- C++ 后端开发
	- SQLite 数据库
	- HTTP API设计
	- Git版本管理
	- Linux部署

# 2.项目背景
	日常生活中需要记录收入和支出情况，
	通过软件帮助用户管理个人财务，
	了解资金流向。

# 3.用户定位

	目标用户：
	
	- 个人用户
	- 需要简单记录收支的人群

# 4.功能需求
## 4.1 账户管理

	V1.0暂不实现用户登录。

	未来支持：
	
	- 用户注册
	- 登录
	- 云同步

## 4.2 记账功能

### 添加记录

	用户可以新增一条账单。
	
	记录内容：

	- 类型
		- 收入
		- 支出
	- 金额
	- 分类
	- 日期
	- 备注

	示例：
	收入：5000元	工资	2026/7/17	兼职工资
	支出：35元	餐饮	2026/7/17	

### 查看记录

	用户可以查看历史账单。

	显示：
	
	- 日期
	- 类型
	- 金额
	- 分类
	- 备注

### 删除记录

	用户可以删除错误账单。
